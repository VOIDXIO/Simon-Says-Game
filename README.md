# Simon Says Game 🎮

A fun and interactive memory game inspired by the classic **Simon Says** challenge. The game tests the player's ability to remember and repeat an increasingly complex sequence of colors. Built using **HTML, CSS, and JavaScript**, this project demonstrates DOM manipulation, event handling, and game logic implementation in a web environment.

## 🚀 Features
- Interactive color-based gameplay
- Random sequence generation for each level
- Increasing difficulty as the player progresses
- Real-time user input validation
- Visual button flash effects
- Game over detection with score display
- Option to restart the game instantly

## 🛠️ Technologies Used
- **HTML5** – Structure and layout of the game
- **CSS3** – Styling, colors, and animations
- **JavaScript (ES6)** – Core game logic and interactivity

## 🎯 How to Play
1. Press any key to start the game.
2. Watch the sequence of flashing colors carefully.
3. Repeat the sequence by clicking the colored buttons in the correct order.
4. Each successful round adds a new color to the sequence.
5. The game ends when you click the wrong color.
6. Your final score will be displayed, and you can restart by pressing any key.
